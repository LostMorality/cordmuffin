# TranslateItAll

TranslateItAll is Translate+ (by Prince527, based on Vencord's Translate) as a userplugin, with Yandex Translate added as a free choice next to Google Translate.

- Turn on **Use Yandex Translate** in the plugin settings. No account or API key needed.
- The first time you translate with Yandex, Equicord asks to allow `translate.yandex.net`. Accept it and restart Discord.
- Languages Yandex doesn't have (Chinese (Traditional), Hawaiian and a few more) go through Google Translate instead. The settings show a note when your target is one of them.
- Translate works on normal messages, forwarded messages, bot messages built from components, and search results (right-click, with FullSearchContext on).
- Toki Pona, Sitelen Pona and Shavian are translated as in Translate+, and the toggles work right away without a restart. Short Toki Pona like "mi pona" and sentences with names ("jan Sonja li pona") are caught too.
- Turn off Translate+ and Vencord's Translate while using this, so you don't get two Translate buttons.
