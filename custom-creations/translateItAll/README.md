# TranslateItAll

TranslateItAll is Translate+ (by Prince527, based on Vencord's Translate) as a userplugin, with Yandex Translate added as a free choice next to Google Translate.

- Turn on "Use Yandex Translate" in the plugin settings. No account or API key needed.
- The first time you translate with Yandex, Equicord asks to allow `translate.yandex.net`. Accept it and restart Discord.
- Toki Pona, Sitelen Pona and Shavian work the same as in Translate+.
- Turn off the built-in Translate+ while using this, so you don't get two Translate buttons.
